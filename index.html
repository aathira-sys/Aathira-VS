My Projects

Ideas transformed into practical learning experiences

ThermoAlert

ThermoAlert is an Arduino-based temperature and humidity monitoring and alert system. It uses a DHT11 sensor to monitor environmental conditions and provides alerts when the measured values cross predefined limits.

Components Used

  • Arduino UNO
  • DHT11 Temperature and Humidity Sensor
  • LED Lights
  • Push Buttons
  • Resistors
  • Buzzer
  • Breadboard and USB Cable

Project Objective

To develop a simple monitoring system that helps users observe temperature and humidity levels and receive alerts when conditions exceed the set limits.
